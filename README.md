## สิ่งที่เพิ่ม
1. **อ่านแบบอัตโนมัติไม่ใช้ AI (Plan2BOQ engine)** — ปุ่มในข้อ 01 และในหน้าต่างเริ่มต้น
   - อ่านรูป/PDF/DXF → ผนัง ช่องเปิด ห้อง เสา → สร้างกริด X/Y + column_omit → สร้างโมเดล 3D + ออกแบบด้วย engine เดิม
   - ใช้ได้นอก Claude (เช่น GitHub Pages) ตอนที่ AI ใช้ไม่ได้
   - แบบสี (มีสีห้อง ต้นไม้) จะใช้เฉพาะเส้นดำ และตัดแนวต้นไม้หรือเส้นประทิ้ง
2. **ถอดงานสถาปัตย์จากแบบเข้า "BOQ ละเอียด"** (ปุ่ม 🧱 ในแท็บ BOQ ละเอียด)
   - ผนังก่อ ฉาบ ทาสี ปูพื้น ฝ้า บัว ประตู หน้าต่าง + งานไฟฟ้า/สุขาภิบาลแบบเหมาต่อ m²
   - ใส่ราคาเริ่มต้น (แก้ได้ทุกช่อง) แล้วรวมกับงานโครงสร้างที่ถอดจากโมเดลตามแบบ ปร.4
   - มี checkpoint: แตะเส้นผนังที่ผิดบนภาพ 2D เพื่อลบ แล้วระบบจะถอดใหม่ทันที
3. **Skill v1.1** — เพิ่ม §9 (อ่านแบบไม่ใช้ AI / ใช้ตรวจเทียบผลของ AI) และ §10 (สูตรถอดแบบงานสถาปัตย์ + BOQ 5 หมวด)
   - skill ที่เคยบันทึกไว้ในเบราว์เซอร์ จะได้ §9 ต่อท้ายให้อัตโนมัติ

## ข้อจำกัด
- ต้องใส่ "กว้างรวมแนวนอน (m)" เพื่อกำหนดมาตราส่วน
- แบบสีแนวโฆษณา: แยกประตูกับหน้าต่างได้ไม่แม่น (ตรวจจำนวนก่อนใช้)
- กริดมาจากตำแหน่งเสาที่ตรวจพบ ต้องตรวจกับแบบโครงสร้างจริง (บันทึกไว้ใน assumptions)
- ถ้าเปิดไฟล์นอก Claude จะมีหน้าต่างพาเข้า Claude ขึ้นมาเหมือนเดิม กด "ใช้แบบออฟไลน์" เพื่อใช้ Plan2BOQ ต่อ

- `index.html` = โปรแกรม (ไฟล์เดียว) · `AI_Structure_Build_Skill.md` = Build Skill v1.1 · `src/plan2boq_engine.js` = engine อ่านแบบ/QTO (ฝังอยู่ใน index.html แล้ว)
- ฟีเจอร์ AI (วิเคราะห์แบบ/Auto Gen/สั่งงาน) ใช้ได้เมื่อเปิดใน Claude
