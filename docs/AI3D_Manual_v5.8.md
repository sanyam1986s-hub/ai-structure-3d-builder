# คู่มือการใช้งาน AI Structure 3D Builder v5.8

AI Structure 3D Builder อ่านแบบ (รูป / PDF / DXF) ด้วย AI แล้วสร้างโมเดลโครงสร้าง 3D (เหล็ก + คสล.) ออกแบบเบื้องต้นตาม ACI / AISC / AISI / วสท. ถอด BOQ แบบ ปร.4 เขียนแบบ 2D และส่งออกไป STAAD, ETABS, AutoCAD, SketchUp ได้ในที่เดียว คู่มือนี้อธิบายลำดับการใช้งาน ทุกปุ่มคำสั่ง และ AI แต่ละชุด พร้อมรูปประกอบ

## 4. แผงซ้าย: นำเข้าแบบและพารามิเตอร์

**01 นำเข้าแบบ**

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| ช่องอัปโหลด / ข้อมูลเพิ่มเติมสำหรับ AI | เหมือนหน้าต่างเริ่มต้น |
| ประเภทโครงสร้าง · รอบตรวจสอบสูงสุด · ☑ ตรวจย้อนกลับ | กำหนดจำนวนรอบที่ AI เทียบโมเดลกับแบบ (ค่าเริ่ม 4) |
| ให้ AI วิเคราะห์แบบและสร้างโมเดล 3D | อ่านแบบ + สร้างโมเดลเท่านั้น |
| 🏛 AI สร้างโมเดลสถาปัตยกรรม (คู่กับโครงสร้าง) | สร้าง/อัปเดตโมเดลสถาปัตย์จากแบบ (นอก Claude ใช้แบบอัตโนมัติจากกริด) |
| 🧱 อ่านแบบอัตโนมัติ (ไม่ใช้ AI) → กริด + ผนัง | Plan2BOQ ไม่ต้องใช้ AI · ใส่ "กว้างรวมแนวนอน (m)" เพื่อกำหนดมาตราส่วน |

**02 พารามิเตอร์ (แก้เองได้ทุกค่า แล้วกด "สร้างโมเดล + ออกแบบเบื้องต้น")**

| กลุ่ม | ค่าที่กรอก |
| --- | --- |
| กริด | ระยะ Grid X / Y (m) · ชื่อ Grid X / Y · ตำแหน่งที่ไม่มีเสา (เช่น 2-B, 3-B) |
| ชั้น | ชื่อชั้น · ความสูงแต่ละชั้น (m) |
| หลังคา | ระบบหลังคา "🤖 AI อัตโนมัติ — อ่านจากแบบ" (ค่าเริ่ม) หรือ "✍ กำหนดเอง" · ความสูงชายคา · ความชัน (°) · ระยะแป · ระยะ Girt · ระยะจันทันเดี่ยว · ค้ำยัน X-Bracing · ฐานเสาเหล็ก ยึดหมุน/ยึดแน่น |
| ฐานราก | qa ดิน (t/m²) · Df (m) · ขนาด/ความยาวเข็ม · น้ำหนักปลอดภัยเข็ม (ตัน/ต้น) |
| ชิ้นส่วนเพิ่ม | JSON extras = คานซอย คานยื่น เสาเพิ่ม ค้ำยัน (พิกัด m) |
| เลือกชนิดชิ้นส่วน | พื้น · เสา · คาน · หลังคา · ฐานราก ฯลฯ ล็อกค่าได้ |

**⚙ ตั้งค่า** — คอนกรีต fc' (210 / 240 / 280 / 320 ksc) · เหล็กเสริมหลัก SD40 / SD50 · ปลอก SR24 · รูปพรรณ SS400 / SM490 / SM520 · LL ตามกฎกระทรวง ฉ.6 ข้อ 15 (150–500 kg/m²) · SDL · DL หลังคา · ผนังบนคาน · แรงลม · ตัวคูณ D / L · หน่วยแบบ (mm / m) · มาตราส่วน (1:50 / 1:100 / 1:200) · กระดาษ (A0–A3) · ข้อมูลโครงการ (ชื่อ เจ้าของ สถานที่ วิศวกร ใบอนุญาต กว.) · ระดับความละเอียด AI (เร็ว / มาตรฐาน / ละเอียดสูงสุด) · **จำนวนหน้า PDF / รูปภาพ / ไฟล์ DXF ที่อ่านสูงสุด (ค่าเริ่ม 100 / 100 / 100)** · ☑ 🏛 สร้างโมเดลสถาปัตยกรรมคู่กับโครงสร้างอัตโนมัติ → กด "บันทึกการตั้งค่า"

**อ่านแบบได้ 100 แผ่น** — AI รับภาพได้จำกัดต่อครั้ง โปรแกรมจึงแบ่งแผ่นที่เกินเป็นชุด ๆ ให้ AI อ่านทีละชุด แล้วสรุปเป็น "SHEET DIGEST" ส่งให้ทุกขั้นต่อไป (อ่านแบบ · ตรวจย้อนกลับ · BOQ · สั่งแก้) ส่วน 📋 ตรวจสอบเอกสารแนบ ก็อ่านทุกหน้าเป็นชุดเช่นกัน

**✦ AI สั่งงาน / สั่งแก้ — ดูผลก่อนยืนยันเสมอ**

![ลำดับการสั่งแก้ด้วย AI](img/flow_edit.svg)

2. กด "ส่งคำสั่ง" — AI อ่านไฟล์และโมเดล
3. Popup เด้งขึ้นแสดง "สิ่งที่แก้ไข" "พารามิเตอร์ที่ปรับ" "หน้าตัดที่เปลี่ยน" และ "ผลต่อโมเดล"
4. กด ✔ ยืนยันแก้ไข → โปรแกรมสลับไปหน้า Model ทันทีพร้อมรายงานจาก AI · หรือ ✖ ยกเลิก ไม่แก้
5. ไม่พอใจผล กด ↶ ย้อนกลับ ได้ทุกครั้ง

**AI Teams — 4 ชุดทำงานเป็นลำดับขั้น**

![ลำดับการทำงาน AI Teams](img/flow_teams.svg)

1. แท็บ AI Teams → ติ๊กเลือกชุดที่ต้องการใน Command Center
2. กด 🚀 รัน AI ทุกชุด + รวมรายงานระบบ (หรือ ▶ รันชุดนี้ ทีละชุด)
3. Stage 1: ชุดคำนวณ + ชุดสถาปัตย์ ทำพร้อมกัน → Stage 2: ชุดเขียนแบบโครงสร้าง + ชุด BOQ

5. แต่ละชุดมีช่อง "สั่งเพิ่มเติม" และ Skill ของตัวเอง (ดูหัวข้อ 9)

## 8. AI เขียนแบบใน AutoCAD โดยตรง (AutoCAD Agent)

![ลำดับการทำงาน AutoCAD Agent](img/flow_acad.svg)

**ติดตั้งครั้งแรก (Windows + AutoCAD เต็มรุ่น)**

1. แท็บ AutoCAD 2D → กด ⬇ ติดตั้ง AutoCAD Agent → ได้ไฟล์ AI3D_AutoCAD_Agent.ps1 และ .bat
2. วางทั้ง 2 ไฟล์ไว้ในโฟลเดอร์เดียวกัน แล้วดับเบิลคลิก .bat — หน้าต่างสถานะ Agent จะเปิดค้างไว้
3. Agent เฝ้าโฟลเดอร์ Downloads หาไฟล์ \*AI3D2D\*.lsp ที่สร้างจากโปรแกรมนี้

**ใช้งาน**

1. เลือกหน่วยแบบ มาตราส่วน รูปแบบ (AutoLISP .lsp / Script .scr) และแผ่นที่ต้องการวาด
2. กด ✦ AI เขียนแบบ → เปิด AutoCAD วาด (ใช้ AI) หรือ "ส่งงานให้ Agent (ไม่ใช้ AI)"
3. Agent เปิด AutoCAD ผ่าน COM → ตั้ง TRUSTEDPATHS → load → รันคำสั่ง AI3D2D → บันทึก DWG ที่ D:\Claude_Project\AI3D_DWG
4. ไม่มี Agent: ใน AutoCAD พิมพ์ APPLOAD เลือกไฟล์ .lsp แล้วพิมพ์ AI3D2D (AutoCAD LT รุ่นเก่าใช้ SCRIPT กับไฟล์ .scr)

**แก้ปัญหา**

| อาการ | วิธีแก้ |
| --- | --- |
| ดับเบิลคลิก .bat แล้วปิดทันที | คลิกขวา .ps1 → Properties → Unblock แล้วรันใหม่ |
| Agent ไม่เห็นไฟล์ | ตรวจว่าเบราว์เซอร์บันทึกลง Downloads และชื่อไฟล์มี AI3D2D |
| AutoCAD ถามความปลอดภัยไฟล์ LISP | Agent ตั้ง TRUSTEDPATHS ให้แล้ว หากยังถาม เลือก "Load Once" |
| AutoCAD LT | LT 2024 ขึ้นไปรัน LISP ได้ รุ่นเก่าใช้ไฟล์ .scr |
