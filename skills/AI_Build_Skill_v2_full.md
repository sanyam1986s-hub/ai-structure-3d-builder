# SKILL: การสร้างโมเดลโครงสร้าง 3D จากแบบ (AI Structure Builder)
เวอร์ชัน 1.0 — ใช้ทุกรอบทั้งการอ่านแบบ (Extract) และการตรวจย้อนกลับ (Verify)

## 1. ลำดับการอ่านแบบ (ทำตามลำดับเสมอ)
1. ระบุชนิดแผ่นแบบแต่ละภาพ: แปลนเสา-คาน (Structural Plan), แปลนสถาปัตย์, รูปตัด (Section), รูปด้าน (Elevation), ตารางเสา/คาน/ฐานราก (Schedule), แบบขยาย (Detail)
2. อ่าน Grid ก่อนทุกอย่าง: นับฟองกริด (Bubble) ทั้งสองทิศ แล้วอ่านระยะระหว่างกริดทุกช่วง ผลรวมต้องเท่ากับระยะรวม (Overall dimension) ถ้าไม่เท่าให้อ่านใหม่
3. อ่านระดับ: ±0.00, +4.00, FFL, TOS, ระดับหลังคา, ชายคา (Eave), สันหลังคา (Ridge) จากรูปตัด/รูปด้าน
4. ไล่แปลนทีละชั้น ทีละช่อง (Bay by bay) จากซ้ายไปขวา ล่างขึ้นบน: เสาทุกต้น คานทุกเส้น พื้น ช่องเปิด
5. ไล่หลังคา: แนว Rafter, ช่วงพาด, ความชัน, แป, ค้ำยัน, กันสาด, ชายคายื่น
6. สรุปสิ่งที่ "อ่านได้จริง" ใน observed_dimensions และสิ่งที่ "สมมติ" ใน assumptions แยกกันชัดเจน

## 2. ข้อตกลงของแบบในประเทศไทย
- หน่วยระยะในแบบโดยทั่วไปเป็น มม. (mm) → แปลงเป็น m (หาร 1000) ระดับมักเป็น m อยู่แล้ว
- ชื่อชิ้นส่วน: C, C1, C2 = เสา คสล. / GB = คานคอดิน / B, B1 = คาน / RB = คานหลังคา / S, S1 = พื้น / F, F1 = ฐานราก / ST = เสาเหล็ก / R = Rafter / P = แป / BR = ค้ำยัน
- คาน "ซอย" (Secondary beam) มักเป็นเส้นคานกลางช่องที่ไม่อยู่บนกริด → ต้องใส่ใน extra_members
- คานยื่น (Cantilever) / กันสาด: ใส่จากจุดต่อที่เสาหรือคานหลัก ออกไปถึงปลายยื่น
- ช่องบันได / ช่องเปิด / ช่องโล่งสองชั้น: ใส่ใน slab_openings ตามระดับชั้น
- พื้นที่ไม่มีเสาที่จุดตัดกริด (เช่น ช่วงโล่ง) → column_omit
- ขนาดหน้าตัดจากตาราง (เช่น C1 30x30, B1 25x50, H-300x150) ให้บันทึกใน observed_dimensions

## 3. กฎระบบพิกัด
- x ตามแนว grid_x, y ตามแนว grid_y, จุดเริ่ม (0,0) = กริดเส้นแรกของแต่ละทิศ, z = ระดับ (Base = 0)
- ทิศยาวของอาคาร (จำนวนช่วงมากกว่า) ให้อยู่แกน X ถ้าแบบไม่ชัดเจน
- Portal frame: โครงอยู่บนกริด X และ Rafter พาดระหว่างกริด Y
- พิกัดปลายชิ้นส่วนเพิ่มเติมต้องตรงกับแนวกริด/คานหลักที่ไปต่อ (ทศนิยม 3 ตำแหน่ง) เพื่อให้โปรแกรมเชื่อมโหนดอัตโนมัติ

## 4. สิ่งที่โปรแกรมสร้างให้อัตโนมัติ (ห้ามใส่ซ้ำใน extra_members)
- ทุกชั้น: เสาทุกจุดตัดกริด (ยกเว้น column_omit), คานทุกเส้นกริดระหว่างจุดตัด, พื้นทุกช่อง
- หลังคาเหล็ก: เสา Portal, Rafter, แป, Girt, Eave strut, X-Bracing ช่วงริม
- ฐานรากใต้เสาที่ลงถึงระดับ 0

## 5. ค่ามาตรฐานเมื่อแบบไม่ระบุ (บันทึกเป็น assumptions)
- ความสูงชั้น 3.5–4.0 m (อาคารทั่วไป), โรงงาน ชายคา 6–8 m, ความชันหลังคาเหล็ก 5–10°, ระยะแป 1.0–1.2 m, Girt 1.5 m
- น้ำหนักบรรทุกจรตามกฎกระทรวง ฉบับที่ 6 (พ.ศ. 2527) ข้อ 15: พักอาศัย 150, สำนักงาน 250, โรงเรียน/พาณิชย์ 300, ที่จอดรถ 400, โรงงาน/คลังสินค้า 500, หลังคา 30 kg/m²
- แรงลม ข้อ 17: สูง < 10 m = 50 kg/m², 10–20 m = 80 kg/m²
- วัสดุ: fc' 240 ksc, SD40, SR24, SS400; qa ดิน 10 t/m²

## 6. Checklist ตรวจย้อนกลับ (ทุกรอบ)
1. จำนวนกริดและระยะทุกช่วง X/Y ตรงกับแบบ
2. ระดับทุกชั้นตรงกับรูปตัด
3. เสาครบทุกต้น ไม่มีเสาเกิน
4. คานครบทุกเส้น รวมคานซอย คานยื่น กันสาด ชั้นลอย
5. พื้นและช่องเปิดครบ
6. รูปทรงหลังคา: ชายคา สัน ความชัน ช่วงพาด ชายคายื่น ค้ำยัน
7. ชนิดโครงสร้างและวัสดุถูกต้อง
8. จุดต่อของชิ้นส่วนเพิ่มเติม: ต่อกับโครงสร้างจริง (ดู Automatic connectivity checks)
9. ประเด็นจากรอบก่อนหน้า: ยืนยันทีละข้อว่าแก้แล้วหรือยัง
- ให้ "complete": true เฉพาะเมื่อไม่มีประเด็น high/medium เหลืออยู่
- ส่ง params กลับแบบเต็มชุดเสมอ และห้ามลบสิ่งที่ถูกต้องอยู่แล้ว

## 7. กฎเพิ่มเติมของผู้ใช้ (แก้ไขได้)

## 8. วิเคราะห์ชนิดชิ้นส่วน (Element types) — ต้องระบุครบทุกข้อ
ระบุใน element_types ทุกครั้ง ถ้าผู้ใช้ล็อกค่าไว้จาก Dropdown ห้ามเปลี่ยน
- ชนิดพื้น (slab_type): มีเส้นคานรอบแผง = พื้นวางบนคาน (two_way / one_way ตาม Ly/Lx), ไม่มีคานภายใน = flat_slab, มีกรอบหนารอบเสา (เส้นประ) = flat_drop, เขียน "HC / Hollow core" = hollow_core, "แผ่นพื้นสำเร็จรูป / PS / Plank" + ลูกศรทิศวางแผ่น = plank, "Metal deck / Deck" = metal_deck, "PT / Post-tension / Tendon" = post_tension, ตง / Joist / Waffle = ribbed
- วัสดุพื้น (slab_material): คสล.หล่อในที่ / อัดแรงสำเร็จรูป / PT / คอนกรีตบน Deck / ตะแกรงเหล็ก (Grating) / แผ่นเหล็กลาย (Checker plate)
- ชนิดเสา (column_type): สี่เหลี่ยม C1 30x30 = rc_rect, วงกลม Ø = rc_circ, H-xxx = steel_h, □-xxx = steel_box, ท่อ Ø / Pipe = steel_pipe, ท่อกรอกคอนกรีต = composite, Precast = precast
- ชนิดคาน (beam_type): คาน คสล. สี่เหลี่ยม / รูปตัว T-L (หล่อพร้อมพื้น) / สำเร็จรูป / PT / H รีดร้อน / Castellated (มีรูหกเหลี่ยม) / Built-up (แผ่นเหล็กประกอบ)
- รูปทรงหลังคา (roof_type): จั่ว / เพิงหมาแหงน / ฟันเลื่อย / โค้ง / ปั้นหยา / แบน คสล.
- โครงสร้างหลังคา (roof_structure): Portal H / Portal tapered (ความลึกเรียว) / Truss เหล็กกล่อง-รูปพรรณ / Truss เหล็กรีดเย็น / พื้นหลังคา คสล.
- ชนิด Truss (truss_type) ดูจากรูปตัดหลังคา: Pratt (มีตั้ง + ทแยงเอียงลงเข้าหากลางช่วง), Howe (ทแยงเอียงขึ้นเข้าหากลางช่วง), Warren (ทแยงสลับ ไม่มีตั้ง), Warren + ตั้ง, Fink (รูป W), King post (ตั้งกลางต้นเดียว), Queen post (ตั้ง 2 ต้น), Scissor (คอร์ดล่างเอียง), Parallel chord (คอร์ดบน-ล่างขนาน), Bowstring (คอร์ดบนโค้ง)
- จันทันเดี่ยว (roof_structure = single_rafter): จันทันเป็นชิ้นเดียววางบนคานหัวเสาและอกไก่ ไม่มีมุมแข็ง (ไม่มี Haunch/Knee) — ถ้ามีจันทันกลางระหว่างเสา ให้ระบุ portal.rafter_spacing_m
- คานหัวเสา (eave_beam_type): ไม่มี (Eave strut) / เหล็ก H / C รีดเย็นคู่ / เหล็กกล่อง / คสล. — ดูจากรูปตัดที่หัวเสาและแปลนหลังคา (เส้นคานรอบอาคารระดับชายคา)
- วัสดุมุง (roof_cladding): เมทัลชีท / เมทัลชีท + ฉนวน PU / กระเบื้องคอนกรีต / เซรามิก-ดินเผา / โพลีคาร์บอเนต → DL หลังคา 15 / 20 / 70 / 80 / 12 kg/m²
- ฐานราก (foundation_type): ฐานแผ่ (F1 ไม่มีเข็ม) หรือ ฐานรากเสาเข็ม (มีสัญลักษณ์เข็มใต้ฐาน, I-0.22, S-0.30, Bored pile) → ระบุ piles.capacity_t / size_cm / length_m ถ้ามีในแบบ
- ทุกชนิดที่ "เดา" ต้องบันทึกใน assumptions พร้อมเหตุผล

## 9. อ่านแบบอัตโนมัติแบบไม่ใช้ AI (Plan2BOQ engine) — ใช้ตั้งต้นและตรวจเทียบ
ปุ่ม "🧱 อ่านแบบอัตโนมัติ (ไม่ใช้ AI)" ทำงานได้แม้เปิดนอก Claude (เช่น GitHub Pages)
1. แปลงภาพเป็นขาว-ดำแบบ adaptive threshold (ถ้าเป็นแบบสี ใช้เฉพาะเส้นที่เกือบดำ) → morphological opening ตัดตัวหนังสือ เส้นเฟอร์นิเจอร์ และลายกระเบื้อง
2. แยกผนังแนวนอน/แนวตั้ง → หา centerline ด้วย LSQ (รับภาพถ่ายที่เอียงเล็กน้อยได้) → snap ปลายผนังเข้าหาผนังที่ตัดกัน
3. รวมผนังที่อยู่ในแนวเดียวกัน: ช่องว่าง 0.55–3.5 m = ช่องเปิด (มีเส้นบางอยู่ในแถบผนัง = หน้าต่าง, ไม่มี = ประตู)
4. ตัดกลุ่มเส้นเล็กที่ไม่ต่อกับอาคาร (เคาน์เตอร์ เฟอร์นิเจอร์) และแนวสัญลักษณ์ซ้ำ (ต้นไม้ เส้นประ) → ต่อปลายผนังอิสระไปชนผนังตั้งฉาก
5. flood-fill หาห้อง (พื้นที่ เส้นรอบรูป) → วางเสาที่มุม/จุดตัดผนัง และแบ่งช่วงไม่เกิน Lmax → จัดกลุ่มพิกัดเสาเป็นกริด X/Y (ไม่มีเสาที่จุดตัดใด = column_omit)
- มาตราส่วน: "กว้างรวมแนวนอน" = ระยะจากผิวผนังซ้ายสุดถึงขวาสุดของอาคาร (ถ้าเว้นว่างไว้จะใช้ระยะกริด X รวมของโมเดลปัจจุบัน) · DXF ใช้หน่วยจาก $INSUNITS และตรวจว่าขนาดสมเหตุผล
- Human checkpoint: แตะเส้นผนังที่ผิดในภาพ 2D ของแท็บ "BOQ ละเอียด" เพื่อลบ แล้วระบบจะถอดงานสถาปัตย์ใหม่ทันที
- เมื่อใช้ AI: ใช้ผลนี้ตรวจเทียบจำนวนช่องกริดและระยะรวม ถ้าต่างเกิน 10% ให้กลับไปอ่านแบบใหม่ และบันทึกเหตุผลไว้ใน assumptions
- ข้อจำกัด: ยังจับผนังเฉียงในภาพไม่ได้ (DXF จับได้) · เฟอร์นิเจอร์ที่เส้นหนาเท่าผนังอาจถูกนับเป็นผนัง · ต้องใส่มาตราส่วนเองเสมอ

## 10. ถอดแบบงานสถาปัตย์ + BOQ (อ้างอิง DDC qto-report / cwicr-takeoff-helper / Thai BOQ 5 หมวด)
- ผนังก่อ = (ความยาวผนังสุทธิ − จำนวนเสา × ความกว้างเสา) × (ความสูงชั้น − ความลึกคาน) − ช่องเปิด + ส่วนเหนือประตู/ใต้และเหนือหน้าต่าง
- ฉาบ = 2 × พื้นที่ผนังก่อ · ทาสี = พื้นที่ฉาบ · ปูพื้น/ฝ้า = พื้นที่ห้องสุทธิ × จำนวนชั้น · บัว = เส้นรอบห้อง − 2 × ความกว้างประตู
- ถ้าแบบไม่ระบุ: ประตูสูง 2.00 m, หน้าต่างสูง 1.10 m (ขอบล่าง 0.90 m) → ต้องบันทึกใน assumptions
- หมวด BOQ: 1 งานเตรียมการ · 2 งานโครงสร้าง · 3 งานสถาปัตยกรรม · 4 งานระบบไฟฟ้า · 5 งานระบบสุขาภิบาล — แยกค่าวัสดุกับค่าแรง ราคาไม่รวม VAT และคูณ Factor F ตามหลักเกณฑ์กรมบัญชีกลาง
- อัตราเหล็กเสริม kg/m³ ใช้เฉพาะเมื่อยังไม่มี bar schedule: ฐานราก 70, เสา 160, คาน 130, พื้น 90, พื้นบนดิน 40 (+5% เผื่อ)
- งานระบบไฟฟ้าและสุขาภิบาลคิดเหมาต่อ m² พื้นที่ใช้สอย จนกว่าจะมีแบบงานระบบ

### 11.1 จัดชุดแบบก่อนอ่าน (drawing-analyzer + architectural-drawing-parser)
- อ่านทีละแผ่น ติดป้ายทุกภาพ ("แผ่น S-01 แปลนฐานราก") แล้วค่อยรวมผล — แผ่นใหญ่ให้ใช้ภาพขยายส่วน (tiles) อ่านตัวเลขเล็ก
- อ่าน Title block ทุกแผ่น: ชื่อโครงการ เลขแผ่น มาตราส่วน หน่วย — ถ้าเขียน NTS / ไม่ได้ตามมาตราส่วน ห้ามวัดจากเส้น ให้ใช้ตัวเลขมิติเท่านั้น
- ลำดับความน่าเชื่อถือ: ตัวเลขมิติที่เขียนในแบบ > ตาราง (Schedule) > ข้อความหมายเหตุ > วัดจากเส้นตามมาตราส่วน > ค่าสมมติ
- DXF: ใช้พิกัดจริงจาก layer (กริด/ผนัง/เสา) และนับ block (ประตู หน้าต่าง สุขภัณฑ์ เสาเข็ม) แทนการนับจากภาพ
### 11.2 โครงสร้างทั้งหลัง (structural-systems + structural-basics)
- เส้นทางถ่ายน้ำหนักต้องต่อเนื่อง: หลังคา → คาน/โครงหลังคา → เสา → ฐานราก → เสาเข็ม/ดิน — ชิ้นส่วนที่ลอย (ไม่มีจุดรองรับ) ให้ถือเป็นประเด็น high
- ตรวจความสมเหตุผลของระยะกริด: บ้าน/อพาร์ตเมนต์ 3–8 m, สำนักงาน 7.5–10.8 m, โรงเรียน 7.5–9 m, ลานจอดรถ 8.1 m, โรงงาน/คลังสินค้า 12–24 m (โครง Portal/Truss) — ถ้าอ่านได้นอกช่วงนี้ให้อ่านซ้ำ
- ระบบต้านแรงด้านข้าง (Moment frame / Bracing / Shear wall) และฐานรากต้องสอดคล้องกับผลเจาะดิน ถ้าแบบไม่ระบุให้บันทึกใน assumptions
- ครบทุกชิ้นส่วน: ฐานราก เสาตอม่อ คานคอดิน พื้นบนดิน เสา คาน คานซอย พื้นทุกชั้น บันได ผนังรับแรง ถังเก็บน้ำ โครงหลังคา แป ค้ำยัน กันสาด
### 11.3 สถาปัตยกรรมทั้งหลัง (construction-documentation) — บันทึกใน observed_dimensions เพื่อใช้ถอดแบบต่อ
- ตารางห้อง: ชื่อห้อง ขนาด และวัสดุพื้น/ผนัง/ฝ้า (Finish schedule)
- ตารางประตู-หน้าต่าง: รหัส (D1, W1) จำนวน ขนาด กว้าง×สูง ชนิด
- ระดับ FFL ของแต่ละห้อง (ห้องน้ำมักต่ำกว่า 5–10 cm), ความสูงฝ้า, ชายคา, วัสดุมุงหลังคา, สุขภัณฑ์ต่อห้อง
### 11.4 รอบตรวจ (verification-loop-construction) — ใช้ทุกรอบ Verify และหลังถอดปริมาณ
1. ข้อมูลครบ: ทุกฟิลด์จำเป็นมีค่า ไม่มีรายการซ้ำ หน่วยเป็นมาตรฐานเดียวกัน (m, m², m³, kg)
2. ตรรกะ: ผลรวมรายการ = ยอดรวมย่อย, ปริมาณอยู่ในช่วงปกติ (เหล็ก/คอนกรีต 80–180 kg/m³, คอนกรีต 0.25–0.45 m³ ต่อ m² พื้นที่ใช้สอย สำหรับอาคาร คสล.)
3. ตรวจเทียบแหล่ง: ผล AI เทียบกับ Plan2BOQ / DXF / ตัวเลขในแบบ → ต่างกันไม่เกิน 5% = PASS, 5–10% = WARN (อธิบายใน notes), เกิน 10% = FAIL (ให้อ่านใหม่)
4. ปริมาณใน BOQ ต้องตรงกับโมเดล 3D เสมอ — ห้ามแก้ปริมาณงานโครงสร้างด้วยมือ

## 12. อ่านแบบให้ครบและตรงตามแบบ (Skill v2.0 — เพิ่มใน v5.8)
ใช้ทุกรอบ ทั้ง Extract และ Verify — เป้าหมาย: ไม่มีชิ้นส่วนขาด ไม่มีชิ้นส่วนเกิน ระยะและขนาดตรงกับตัวเลขในแบบ
### 12.1 ทำสารบัญแบบก่อน (Sheet index)
- ไล่ทุกแผ่น (รวม SHEET DIGEST ที่ AI อ่านไว้แล้ว) ระบุ: เลขแผ่น ชื่อแผ่น ชนิด มาตราส่วน ระดับชั้นที่แผ่นนั้นแสดง
- หาแผ่นสารบัญ (Drawing list) ถ้ามี แล้วเทียบว่าแผ่นไหนขาด → ใส่ใน issues ว่า "ไม่มีแผ่น …"
- ตาม Callout ทุกอัน: สัญลักษณ์รูปตัด A-A / 1-S-201, แบบขยาย, อ้างอิงตาราง — ไปอ่านแผ่นปลายทางทุกครั้ง
- แบบหลายฉบับแก้ไข (Rev.) ให้ใช้ฉบับล่าสุด · แบบขยายมาตราส่วนใหญ่ชนะแปลนมาตราส่วนเล็ก
### 12.2 นับของก่อนสร้าง (Inventory first)
- ก่อนตอบ params ให้นับทีละชั้นแล้วเขียนใน observed_dimensions เป็นบรรทัดขึ้นต้น "INVENTORY" เช่น
  "INVENTORY ชั้น 1: Grid X 6 เส้น Y 4 เส้น · C1×14 C2×6 · B1×22 B2×9 คานซอย×4 · F1×14 F2×6 · เข็ม I-0.22×52"
- params ที่ส่งกลับต้องสร้างจำนวนเสา/คาน/ฐานรากได้เท่ากับ INVENTORY — ถ้าไม่เท่าให้แก้ (column_omit, extras) หรือแจ้ง issue high
- รอบ Verify: นับจากโมเดลเทียบ INVENTORY ทุกชั้น ต่างกันแม้ 1 ชิ้นถือว่ายังไม่ครบ
### 12.3 ระยะและหน่วย (Dimension chain)
- อ่านเส้นบอกระยะทั้งแถว (Chain) ทุกช่วง แล้วรวมเทียบระยะรวมนอกสุด ต่างเกิน 0.5% ให้อ่านใหม่จากภาพขยาย
- ตัวเลข ≥ 100 ไม่มีทศนิยม (6000, 4500) = mm → ÷1000 · ตัวเลขมีทศนิยม 2 ตำแหน่ง (6.00, 4.50) = m · ระดับ (+3.50, ±0.00) = m
- ห้ามวัดจากภาพเมื่อมีตัวเลขเขียนไว้ · ถ้าจำเป็นต้องวัด ให้เทียบมาตราส่วนกับระยะที่มีตัวเลขก่อน แล้วบันทึกเป็น assumptions
- เสา/คานเยื้องศูนย์จากกริด (Offset) ให้อ่านระยะเยื้องแล้วบันทึก "C3 เยื้อง +0.15 m จากกริด B"
### 12.4 ตาราง (Schedule) → ชิ้นส่วน
- ตารางเสา: รหัส × ช่วงชั้น → ขนาด + เหล็กยืน + ปลอก (เช่น C1 ชั้น 1–2 40×40 12-DB20 RB9@0.15, ชั้น 3–หลังคา 30×30) บันทึกครบทุกช่วงชั้น
- ตารางคาน: รหัส → b×h, เหล็กบน/ล่าง ที่ปลายและกลางช่วง, ปลอก · คานที่ไม่มีในตารางแต่มีในแปลน = issue
- ตารางฐานราก: รหัส → กว้าง×ยาว×หนา, จำนวนเข็ม, ขนาด/ความยาวเข็ม, น้ำหนักปลอดภัย · ตารางพื้น: รหัส → หนา, ชนิด, เหล็กเสริม
- จับคู่ทุกรหัสในแปลนกับตาราง ถ้ารหัสในแปลนไม่มีในตาราง หรือรหัสในตารางไม่ปรากฏในแปลน ให้แจ้ง issue
### 12.5 สัญลักษณ์แบบไทยที่ต้องรู้
- ตัวย่อ: ส./C = เสา · ค./B = คาน · คอ./GB = คานคอดิน · พ./S = พื้น · ฐ./F = ฐานราก · ตม./ST = เสาตอม่อ · บ./ST = บันได · ผ./W = ผนัง
- เหล็ก: DB = ข้ออ้อย, RB = กลม, "4-DB16" = 4 เส้น Ø16 mm, "RB9@0.15" = ปลอก Ø9 ทุก 0.15 m, ระยะหุ้ม (Covering)
- เส้น: เส้นทึบหนา = ชิ้นส่วนที่ถูกตัด/มองเห็น, เส้นประ = ชิ้นส่วนใต้พื้น/ด้านล่าง (คานใต้พื้น ฐานราก), เส้นประยาว-สั้น = แนวกริด/แกน
- พื้นที่แรเงา/ไขว้ (X) = ช่องเปิด ช่องบันได ช่องลิฟต์ ช่องท่อ → slab_openings
### 12.6 กระทบยอดระหว่างแผ่น (Plan ↔ Section ↔ Elevation)
- ความสูงชั้น/ระดับ ใช้รูปตัด/รูปด้านเป็นหลัก · ตำแหน่งในแนวราบใช้แปลน · รูปทรงหลังคาใช้รูปตัดหลังคา
- กริดต้องตรงกันทุกแผ่น (ชื่อและระยะ) ถ้าไม่ตรงให้ใช้แปลนโครงสร้างเป็นหลักและแจ้ง issue medium
- ชิ้นส่วนที่เห็นในรูปตัดแต่ไม่มีในแปลน (หรือกลับกัน) ต้องแจ้งทุกครั้ง
### 12.7 ห้ามเดา — บอกสิ่งที่อ่านไม่ได้
- ตัวเลขที่อ่านไม่ชัด ให้ใส่ใน issues ว่า "อ่านไม่ได้: แผ่น … บริเวณ …" และใช้ค่าจากแผ่นอื่นถ้ามี ไม่ใช่ค่ามาตรฐาน
- ค่าสมมติทุกค่าต้องอยู่ใน assumptions พร้อมเหตุผล — ห้ามปนกับ observed_dimensions
### 12.8 ตรวจตัวเองก่อนตอบ (ทุกรอบ)
1. ทุกแผ่นถูกอ่านแล้ว (รวม SHEET DIGEST) และไม่มี Callout ที่ยังไม่ได้ตาม
2. ผลรวมระยะกริดทุกทิศ = ระยะรวมในแบบ
3. INVENTORY ทุกชั้น = จำนวนที่โมเดลจะสร้าง
4. ทุกรหัสชิ้นส่วนจับคู่กับตารางได้ ขนาดตรงกับช่วงชั้น
5. ระดับทุกชั้น + ชายคา + สัน ตรงกับรูปตัด
6. ช่องเปิด คานซอย คานยื่น กันสาด ชั้นลอย บันได อยู่ครบ
7. assumptions มีเฉพาะสิ่งที่แบบไม่ได้ระบุจริง
